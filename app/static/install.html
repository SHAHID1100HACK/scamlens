Install the ScamLens extension

Select any suspicious text on a web page, right-click, and get an explained risk score with the warning signs highlighted right on the page. Works on Chrome, Edge, Brave and Firefox.

1. Download

Download extension (.zip)

Verify the download (optional)

Linux/macOS: sha256sum scamlens-extension-*.zip
Windows: certutil -hashfile scamlens-extension-v0.1.0.zip SHA256
The result must match the value above.

2. Install in Chrome, Edge or Brave

  1. Unzip the file. You should get a folder containing manifest.json.
  2. Open chrome://extensions in your browser.
  3. Turn on Developer mode (top-right switch).
  4. Click Load unpacked and choose the unzipped folder. Pin ScamLens from the puzzle-piece menu.

Chrome shows a Developer-mode notice for extensions installed this way. That is expected for this free version, which is not in the Chrome Web Store.

Firefox

  1. Unzip the file, then open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on and choose manifest.json from the unzipped folder.
  3. Open about:addons, click ScamLens, then Permissions, and allow access to the ScamLens site.

Firefox removes temporary add-ons when it closes, so repeat step 2 after a restart.

3. Use it

  • Select text on any page → right-click → Check with ScamLens.
  • Or click the toolbar icon → Analyze this page.
  • Press Highlight on page to mark the exact warning phrases.

What it can access, and why

PermissionWhy
activeTab + scriptingReads the text you select, or the page you ask it to analyze, only when you click. No always-on scripts.
contextMenusThe right-click “Check with ScamLens” item.
storageRemembers your latest result for the popup.
One server addressSends the text to the ScamLens server for analysis. Nothing else is contacted.

Card numbers and OTP-like values are masked inside the extension before anything is sent. Nothing is stored on the server. The extension is plain, readable JavaScript with no libraries, and the source is in the project's GitHub repository.
